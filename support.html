Help

Support

Stuck, found a bug or have an idea? Email lance@landchit.dev. Say which device you're on and your Noggin version (Settings → About).

Common questions

Do I need an account or internet?

No. Noggin works entirely offline and has no accounts. When you're online, it checks once a day whether a newer version is out, and tells you once.

How do I move my data to a new phone or PC?

On the old device, go to Settings → Backup & export → Back up and save the .noggin file somewhere you can reach from the new device. On the new device, open that file with Noggin or use Restore a backup. Restoring replaces what's already there, so Noggin asks you to type RESTORE first.

What's the difference between a backup and an export?

A backup (Noggin backup 2026-09-30.noggin) is your whole library and replaces everything when you restore it. An export (… (Noggin export).noggin) holds the sets or courses you picked, and importing it adds them to what you already have.

Can I bring my Anki decks?

Yes. Pick an .apkg file, choose which fields become the front and back, and check the preview before anything is added.

How does Import from text work?

In Settings → Backup & export → Import from text, copy the instructions into any AI chat along with your notes. Paste the AI's answer back into Noggin. It builds a set and shows any line it couldn't read, with the line number. Check the content before you study from it.

I'm not getting reminders.

Check that notifications are on for Noggin in your device settings. On Android 12 and later, also allow Alarms & reminders. Some phones put apps to sleep to save battery. If yours does, turn battery optimisation off for Noggin.

Windows says the installer is from an unknown publisher.

The installer isn't code-signed yet. If you downloaded it from the official link on this site, choose More info → Run anyway.

The Linux AppImage won't open.

First allow it to run: right-click the file, open Properties → Permissions and tick Allow executing file as program, or run chmod +x Noggin-*.AppImage. If it still doesn't start on Ubuntu or Mint, install FUSE 2 with sudo apt install libfuse2 (on Ubuntu 24.04, libfuse2t64) and try again.

How do I update Noggin on Linux?

Put the new AppImage in the same folder as the old one and open it once; Noggin offers to take over your app menu entry and delete the old file. Gear Lever and AppImageUpdate can also update it in place. The full steps are in Updating Noggin on Linux below.

Updating Noggin on Linux

Your notes, quizzes and cards are kept in ~/.local/share/dev.landchit.noggin, not in the AppImage, so updating only swaps the app file. The new version opens right where you left off. Pick one of these three ways.

Download the new AppImage

The simplest way, and it needs nothing else installed.

  1. Download the new AppImage with the Linux download button.
  2. Put it in the same folder as the old one, for example ~/Applications. There's no need to rename it: the version number in its name is fine. Keeping them together keeps your files tidy, and the old one is easy to find.
  3. Allow it to run: right-click it, open Properties → Permissions and tick Allow executing file as program, or run chmod +x Noggin-*.AppImage.
  4. Open it once from your file manager. If you added Noggin to your app menu with Settings → Add to app launcher, it asks Use this version from your app menu? Choose Update and delete the old file. Your app menu now opens the new version, and only one Noggin file is left.

Didn't add Noggin to your app menu? Delete the old AppImage yourself once the new one opens. Chose Not now by mistake? Open the launcher page again (Settings → Add to app launcher) and create the entry from the new version.

Update in place with Gear Lever

Gear Lever manages AppImages for you. It adds them to your app menu and updates them where they are, downloading only the parts that changed.

  1. Install it from Flathub, from your software centre or with flatpak install flathub it.mijorus.gearlever.
  2. Open Noggin's AppImage with Gear Lever (or drag it onto Gear Lever's window) and add it to your app menu.
  3. When a new version is out, open Gear Lever and use its update check on Noggin.

Gear Lever puts Noggin in your app menu itself, so skip Noggin's own Add to app launcher, or Noggin shows up twice. If you already used it, delete ~/.local/share/applications/dev.landchit.noggin.desktop.

Update in place with AppImageUpdate

For the terminal. appimageupdatetool also downloads only what changed.

  1. Download appimageupdatetool-x86_64.AppImage from AppImageUpdate's releases and allow it to run (chmod +x appimageupdatetool-x86_64.AppImage).
  2. Point it at your Noggin, using the file's real path:
    ./appimageupdatetool-x86_64.AppImage --overwrite ~/Applications/Noggin-0.0.4-x86_64.AppImage

--overwrite updates the file where it is, so its name and your app menu entry stay the same. The name keeps the old version number; Settings → About shows the real one. Leave --overwrite out to get the new version as a separate file beside the old one, then open it once, as in the first way.

If Gear Lever or AppImageUpdate says there's no update, or can't check, download the new AppImage from this site instead.

Deleting your data

Everything is on your device, and there's no account to close. To remove it all:

  • Android: Settings → Apps → Noggin → Storage → Clear storage, or uninstall Noggin.
  • Windows: uninstall from Settings → Apps and answer Yes to Also delete your Noggin data?
  • Linux: delete the AppImage and the ~/.local/share/dev.landchit.noggin folder.
